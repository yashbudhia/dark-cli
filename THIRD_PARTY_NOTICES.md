Earlier Git revisions contain Framer-template-derived decorative PNGs and a shader.
Those historical assets are excluded from Dark's MIT grant and remain subject to
their upstream terms. The current tree replaces those decorative assets with
original CSS gradients and an original shader. No Framer template license is
granted by this repository.
